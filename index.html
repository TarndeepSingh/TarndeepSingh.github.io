Ongoing

An end-to-end machine learning pipeline that turns sign language video into predictions, from dataset analysis to model evaluation.

  • Uses MediaPipe Holistic to pull pose, hand and face landmarks from each frame and turn video sequences into structured numerical features.
  • Tests temporal preprocessing, data augmentation and class balancing to help the model generalize across gesture classes.
  1. Video clipsRecorded gestures, analyzed before any modelling
  2. MediaPipe HolisticPose, hand and face landmarks per frame
  3. Feature sequencesLandmarks as numeric arrays over time
  4. PreprocessingTemporal handling, augmentation, class balancing
  5. Deep learningTensorFlow models evaluated per gesture class
